# SENTINEL ring station viewer: build prompt

Use the sentinel-ring-station, cinematic-post-pipeline and sentinel-design-system skills.

Build a full-screen three.js viewer (vendored three.js with an import map, no CDN) for a ring space station generated by a Blender script and loaded as a GLB with named anchor empties.

- Scene: nebula sky, stars, a ringed ice giant on the right, a distant pale-blue home planet, one white sun with soft shadows, camera-space dust motes.
- Station: twelve modules on a ring, hub with dish, solar wings, slow sway and bob. A canvas-painted PMREM environment for reflections.
- Four modes as pill buttons, each easing one effect channel to 1: Transmit (downlink beam with 16-chip packets and wavefront rings), Open bay (door swings, cipher-core lattice and glyph band light up), Hologram (carrier image projected from the imaging lens), Waveform (instanced bar ring around the comms helix).
- Post: mip bloom, ACES, cool/warm split tone, light chromatic aberration, grain.
- Drag to rotate with inertia and idle drift. On phones, centre the station and pull the camera back.
- Copy top-left over a directional scrim: eyebrow, "Hidden in *the noise.*", one line about the station.
- Preloader that finishes on the first rendered frame (8 s cap). Reduced motion: no drift, effects snap.
- Verify at 1280x720 and 390x844 over http with an empty console.
