# Build prompt: SentinelSpread-style mission page

Use the sentinel-ring-station, sentinel-design-system, editorial-scroll-story, scroll-chapter-camera, cinematic-post-pipeline, pinned-3d-annotations and liquid-glass-workbench skills.

Create a single-page WebGL experience called **[Name]**: a cinematic flight around [one hero object, e.g. a ring-shaped relay satellite] in deep space, where each chapter explains one part of [the product] and the page ends in a workbench of real, working tools. It should feel like an editorial mission dossier, not a SaaS landing page.

## Experience

- Fixed full-viewport Three.js canvas (vendored, import map, no CDN). The hero object is generated by a Blender Python script and exported as a GLB with named anchor empties per part (see sentinel-ring-station); around it a nebula sky, stars, a ringed gas giant, a distant pale-blue target world, one white sun casting soft shadows.
- Scroll flies the camera through one authored shot per chapter (ledger: cam, target, control point, fov, orbit, tilt, roll, fx). Moves swoop along Bezier curves, bank into lateral motion, and the lens breathes on fast scrolls.
- Each chapter also animates the object: [a bay door opens, a downlink beam fires, a hologram appears, a waveform ring pulses].
- Post: mip bloom, ACES, split-tone grade, light chromatic aberration, fine grain. Palette: navy ink #04060d, text #e9eef6, one accent #8ecbff.

## Layout

- Hero: eyebrow "Chapter 00 — [subtitle]", H1 "[Two words] *[accent phrase.]*", a lede, "Drag to rotate · Scroll to fly" cue, four numbered chips, a giant outlined wordmark behind.
- [N] chapters, each: eyebrow naming the part ("Chapter 01 — Command module"), H2 with an accent phrase, one paragraph that ends on a number, a spec list (label in small caps, mono value), and a button into the matching workbench tool. One chapter puts its copy on the right.
- Annotation tags pinned to the object's parts, the current chapter's part in focus.
- Workbench: clear liquid glass console, searchable grouped nav, one tool on stage with Input and Output columns, results as readings and verdicts. Status pill in the top bar shows whether the API is up.

## Motion

- Heading words rise from masks; body, spec and actions follow in sequence. Rail dashes grow for the current chapter. Scrim follows the copy's side.
- Preloader finishes on the first rendered frame, never later than 6 seconds.
- Reduced motion: shots cut instead of fly, no roll, no breathe, all copy visible.

## Interaction and quality

- Custom ring cursor on fine pointers only, hidden over the workbench. Drag-to-rotate only in the hero.
- Skip link, landmarks, aria labels, `aria-live` on outputs. Works without WebGL (story and tools still usable, with a notice).
- Pixel ratio capped at 1.5 desktop / 1.25 touch, no MSAA on phones, compile shaders before the first frame.
- Verify at 1440x900 and 390x844: every chapter framed, tags never over copy, no 404s, empty console, one full scroll and one tool run.
