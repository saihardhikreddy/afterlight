Create a single-page [kind of experience] called **[Name]**: [one sentence on what it is and how it should feel]. It should feel like [a reference feeling], not [the generic thing to avoid].

## Experience

- [The focal element and how it's made: DOM, canvas, WebGL, video.]
- [What drives it: scroll, pointer, time, a button.]
- [Atmosphere and effects, each with a reason.]
- Keep the palette to [3 to 5 named colors with hex values].

## Layout

- Structure the page as [sections in order].
- Type: [families, scale, case, alignment]. Spacing: [rhythm].
- [What's pinned, layered or full-bleed. Where media sits.]

## Motion

- [What moves, what triggers it, duration and easing.]
- [Section transitions and reveals.]
- Include reduced-motion behavior that keeps the full content and a finished static state.

## Interaction and quality

- [Controls, navigation, cursor behavior.]
- Responsive at desktop and about 390 × 844. Semantic landmarks and accessible labels.
- Keep assets local with relative paths so it works under a GitHub Pages subpath.
- Avoid [frameworks, build tools, CDNs, analytics, remote fonts, placeholder imagery, generic glassmorphism, glow without purpose].
- Before shipping: screenshot at both sizes, check for 404s, an empty console, and one full interaction pass.
